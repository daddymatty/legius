# Бібліотека бланків LEGIUS — конвенція плейсхолдерів

Всі бланки в Zoho Writer використовують плейсхолдери у форматі `{{НАЗВА}}`.
Заповнення: вручну (Find & Replace) або через Claude; формат сумісний
з майбутнім Mail Merge із CRM (поля мапляться 1:1).

## Готові шаблони (v1, 23.07.2026)

| Шаблон | Джерело |
|---|---|
| Договір про надання правничої допомоги | знеособлено з робочого договору |
| Додаткова угода (погодинний гонорар) | знеособлено; виправлено баг-«хвіст» із чужим номером договору в п. про невід'ємну частину |
| Рахунок-фактура | знеособлено, включно з контактами у футері |

## Словник плейсхолдерів

### Адвокат
| Плейсхолдер | Зміст |
|---|---|
| `{{АДВОКАТ_ПІБ}}` | ПІБ повністю |
| `{{АДВОКАТ_ПІБ_СКОР}}` | Прізвище І.Б. (для підпису) |
| `{{АДВОКАТ_СВІДОЦТВО_НОМЕР}}` / `{{АДВОКАТ_СВІДОЦТВО_ДАТА}}` / `{{АДВОКАТ_СВІДОЦТВО_ОРГАН}}` | свідоцтво про право на заняття адвокатською діяльністю (орган — в орудному відмінку: «Радою адвокатів …») |
| `{{АДВОКАТ_АДРЕСА}}` | адреса робочого місця |
| `{{АДВОКАТ_ТЕЛЕФОН}}` / `{{АДВОКАТ_EMAIL}}` | контакти |
| `{{АДВОКАТ_РНОКПП}}` / `{{АДВОКАТ_IBAN}}` / `{{АДВОКАТ_БАНК}}` / `{{АДВОКАТ_МФО}}` | платіжні реквізити (рахунок) |

### Договір / угода / рахунок
| Плейсхолдер | Зміст |
|---|---|
| `{{НОМЕР_ДОГОВОРУ}}` / `{{ДАТА_ДОГОВОРУ}}` | основний договір |
| `{{СТРОК_ДІЇ_ДО}}` | «діє до …» (напр. «31 грудня 2027 року») |
| `{{НОМЕР_УГОДИ}}` / `{{ДАТА_УГОДИ}}` | додаткова угода |
| `{{ПРЕДМЕТ_ДОРУЧЕННЯ}}` | опис доручення (одним реченням, з ким/про що) |
| `{{СТАВКА_ГОДИНА}}` / `{{СТАВКА_ПРОПИСОМ}}` | погодинна ставка цифрами / прописом |
| `{{РАХУНОК_НОМЕР}}` / `{{РАХУНОК_ДАТА}}` | рахунок-фактура |
| `{{СУМА}}` / `{{СУМА_ПРОПИСОМ}}` | сума рахунку цифрами / прописом |

## Правила

1. Нові бланки — ті самі плейсхолдери; нові додавати в цей словник.
2. Номер договору за конвенцією фірми: `ДДММ-N/РР` (напр. 0910-2/25).
3. Прописи сум — з малої літери, у дужках: `(дванадцять тисяч п'ятсот гривень 00 копійок)`.
4. У Writer бланки зберігаються в папці `Бланки LEGIUS/01 Договори` (структуру див. setup-guide.md, крок 7).
