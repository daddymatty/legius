# CRM LEGIUS — робочий простір адвокатів на Zoho

Ця папка — документація окремого напряму «CRM» (не стосується сайту/SEO/реклами).

**Мета:** Zoho CRM Free (до 3 користувачів) як робочий простір адвокатів, а не CRM для продажників:

- на першому місці — **задачі, календар, зустрічі/засідання**;
- модуль Deals перейменовано на **«Справи»** з юридичними етапами:
  Консультація → Договір → Провадження → Суд → Виконання → Закрито;
- **Ліди** — просто вхідний кошик заявок (з сайту та пошти);
- бібліотека бланків документів у **Zoho Writer** (безкоштовний рівень, без Mail Merge поки);
- офіційний **конектор Zoho CRM у claude.ai** — Claude як асистент усередині CRM.

## Межі відповідальності

- **Ця сесія:** CRM, Writer-бланки, конектор Claude.
- **Сесія сайту:** сайт, SEO, реклама, інтеграція форми сайту з CRM через Cloudflare Worker.
  Коли CRM буде готова — передати туди API-дані (див. крок 10 у гайді).
