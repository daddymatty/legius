# CRM LEGIUS — робочий простір адвокатів на Zoho

Ця папка — документація напряму «CRM» (не стосується сайту/SEO/реклами,
крім файлу site-integration.md — стикування з воркером сайту).

**Мета:** Zoho CRM Free (до 3 користувачів) як робочий простір адвокатів,
а не CRM для продажників: задачі/календар/засідання на першому місці,
Deals → «Справи» з юридичними етапами, Ліди → вхідний кошик «Заявки»,
бібліотека бланків у Zoho Writer, конектор Zoho CRM у claude.ai.

> Історія: липневі коміти цієї папки загубилися при перестворенні гілки
> (PR не був злитий у main); 09.09.2026 документацію відновлено.

## Технічні нотатки

- **Дата-центр EU**: усе API — `accounts.zoho.eu` / `www.zohoapis.eu`.
- **Picklist через API**: передавати display-значення як в UI («Нова»,
  «Консультація»); en-актуали Zoho пише сирим рядком (перевірено).
- Модулі активностей (Tasks/Meetings/Calls) перейменувати не можна —
  системні; вирішено мовою інтерфейсу (en: Meetings/Tasks/Calls).
- Видалені значення picklist Zoho зберігає як `type: unused` — це норма,
  в UI їх нема.
